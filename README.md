
# PneumoAI

An educational deep learning project for classifying chest X-ray images as Normal or Pneumonia.

## Project Status

Planning and initial setup.

## Objectives

- Prepare and explore a chest X-ray dataset.
- Develop a baseline Convolutional Neural Network (CNN).
- Compare the baseline model with ResNet50 and MobileNetV2.
- Evaluate models using accuracy, precision, recall, F1-score, and ROC-AUC.
- Explore Grad-CAM for visual explanations of model predictions.
- Build an interactive web interface using Streamlit.

## Technology Stack

- Python
- PyTorch
- NumPy and Pandas
- Matplotlib and scikit-learn
- OpenCV
- Streamlit

## Disclaimer

PneumoAI is an educational research prototype, not a clinically
validated diagnostic system. Its predictions must not be used
to make medical decisions.
